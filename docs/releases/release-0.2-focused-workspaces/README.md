# Release 0.2: Focused workspaces

## Status

In progress. MRA-008 is implemented; MRA-009 is planned as the next independently complete story.

## Objective

Give documents and conversations focused workspaces while making source selection and everyday chat controls easier to manage.

## Story map

| Story | Title | Status |
| --- | --- | --- |
| MRA-008 | Manage document availability in a dedicated workspace | Implemented |
| MRA-009 | Refine chat interaction and conversation controls | Planned |

## Release boundary

MRA-008 changes document selection for retrieval without changing ingestion, stored chunks, or model compatibility. MRA-009 owns editable conversation titles and the remaining chat UI refinements.
